# Music

## Metadata Preparation
Most common steps for music purchased and downloaded from Bandcamp, Qobuz, 7Digital, or similar places.

1. Find the download page and download the album
2. Rename the `.tar` (or `.zip`) file to `Artist -- Album Title.ext` (leave off things such as "Deluxe Edition", or "Special Edition", or "Soundtrack", etc)
3. Unzip the `.tar` but keep the original for archival purposes -- move to `/Volumes/external/Archives/Music/Hi-Res Originals`
4. Rename the folder to the album title
5. For any extras:
   - save album art as `cover.jpg`
   - save booklet as `booklet.pdf`
6. Open the album in Meta.app and fix the metadata
   - filename should be `track no. title` or `disc no.-track no. title`
   - replace the lo-res artwork already existing with the artwork downloaded in the previous step
   - remove any text in the "Comments" field
   - track titles should NOT include `[feat. XYZ]` but SHOULD include `[Demo]` or `[Acoustic]` when appropriate
7. Take note of the Bit Depth and Sample Rate. Use these when cataloguing in the Digital Inventory.numbers > Music spreadsheet
8. Move folder to `/Volumes/external/Music/Main Library` and categorize by album artist
9. Rescan the library in Navidrome
